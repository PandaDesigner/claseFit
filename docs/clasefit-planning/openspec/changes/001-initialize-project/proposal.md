# Proposal: Inicializar base técnica de ClaseFit

## Why

El reinicio necesita una base reproducible para aplicar SDD y TDD antes de crear lógica de reservas.

## What Changes

Crear el proyecto Expo TypeScript, inicializar OpenSpec, configurar Jest y establecer aliases/rutas feature-first. No se implementan reglas de reserva ni pantallas finales.

## Impact

Afecta configuración, scripts, contexto OpenSpec y prueba smoke. Desbloquea todos los cambios posteriores.
