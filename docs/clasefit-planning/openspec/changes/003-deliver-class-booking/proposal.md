# Proposal: Entregar funcionalidad de reservas ClaseFit

## Why

Con los requisitos y contratos aprobados, la aplicación necesita adaptadores, pantallas y evidencia verificable sin acoplar reglas de negocio a React Native.

## What Changes

Implementar adapters de Zustand/AsyncStorage/Clock, casos de uso, hidratación serializada, navegación de dos pestañas y estados de interfaz.

## Impact

Afecta la funcionalidad class-booking y agrega pruebas TDD de contratos, integración y presentación.
